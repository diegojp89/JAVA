🚀 Projeto Java - Primeiro Projeto

📌 Sobre o projeto

Este é um projeto simples em Java que interage com o usuário via terminal.

O sistema solicita o nome e a idade do usuário, processa essas informações e exibe uma mensagem personalizada ao final.

🎯 Funcionalidades

Entrada de dados pelo teclado
Armazenamento de informações em variáveis
Exibição de mensagem personalizada

🛠️ Tecnologias utilizadas
☕ Java
💻 IntelliJ IDEA
🔧 Git e GitHub

📚 O que estou aprendendo

Estrutura básica de um programa em Java
Entrada e saída de dados
Lógica de programação
Versionamento com Git

📂 Estrutura do projeto

O código principal está localizado em: src/Main.java

Onde ficam as classes Java do projeto.

▶️ Como executar o projeto

Clone o repositório:

git clone https://github.com/diegojp89/JAVA.git
Abra no IntelliJ IDEA
Execute a classe principal
